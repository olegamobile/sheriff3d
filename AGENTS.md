## 1. Контекст и цель проекта

- **Проект:** Высокоточная параметрическая 3D-модель классической парусно-моторной яхты **Jouët Sheriff 600** (конструктор — Philippe Harlé, верфь — Yachting France, Франция, 1969).
- **Целевой 3D-принтер пользователя:** **Flashforge Adventurer 3** (рабочая зона 150 × 150 × 150 мм, диаметр сопла 0.4 мм).
- **Масштаб:** **1:45** (длина модели LOA = 133.3 мм, ширина Bmax = 52.3 мм, высота ватерлинейной части 26.8 мм). Вся модель гарантированно помещается на стол принтера. Также экспортируются файлы 1:1 (LOA = 6000 мм).
- **Текущее состояние (V3):**
  - Подводная часть, форма корпуса, транец, чугунный фальшкиль и навесной руль полностью согласованы и соответствуют чертежам.
  - **Пользователь уже может печатать нижнюю часть с килем (`Jouet_Sheriff_Split_Keel_1to45.stl`).**
  - **ПРЕДСТОЯЩАЯ ЗАДАЧА ДЛЯ ВАС:** Пользователь пришлет реальные фотографии своей лодки и точные замеры деталей палубы, рубки, кокпита и люков. Ваша задача — внести индивидуальные правки в **палубную часть** (`Split_Deck` / `Waterline`), сохранив идеальную стыковку с уже готовым килем!

## 2. Архитектура кода и генератора

Основной скрипт генерации: **`generate_sheriff_models.py`**.

### Топология «Шпангоутных колец» (Ring Topology)
Корпус строится не через сшивание отдельных граней (что вызывало дыры в сетке), а методом непрерывных замкнутых колец в функции `get_sheriff_ring(x)`:
1. Квартет сплайнов (`CubicSpline` по 13 шпангоутам): `cs_sheer`, `cs_beam`, `cs_keel`.
2. Каждое сечение при координате $X$ формирует замкнутый полигон:
   - Киль $\to$ Правый борт (суперэллипс $p, q$ в зависимости от шпангоута) $\to$ Правый привальный брус (выпуклый валик) $\to$ Палуба / Рубка / Кокпит $\to$ Левый привальный брус $\to$ Левый борт $\to$ Киль.
3. 121 кольцо вдоль корпуса соединяются в непрерывный цилиндрический чулок и закрываются плоскими заглушками транца ($X=0$) и форштевня ($X=6000$).
4. **Результат:** сетка гарантированно является **100% Watertight 2-manifold** (эйлерова характеристика $V - E + F = 2$, 0 открытых ребер).

### Булевы операции через `manifold3d`
Для объединения и разрезания используется движок `manifold3d` (официальный C++ CSG-движок, используемый в Blender и OpenSCAD):
- `m_full = mh + mk + mp` (Корпус + Фальшкиль + Подпятник мачты)
- `m_wl = m_full - m_cut_box` (Срез по КВЛ $Z=0$ для ватерлинейной модели)
- `m_deck_split = m_wl - m_pins` (Палуба со стыковочными пазами)
- `m_keel_split = m_bottom - m_pins` (Киль с плоским верхом $Z=0$ и стыковочными пазами)

## 3. Критические правила для Агента

### ⚠️ ПРАВИЛО 1: Сохраняйте координаты стыковочных отверстий!
Пользователь печатает нижнюю часть (`Jouet_Sheriff_Split_Keel_1to45.stl`), в которой уже заложены два центровочных отверстия на плоскости ватерлинии ($Z=0$):
- **Носовое отверстие:** $X = 3800.0\text{ мм}$ ($X = 84.44\text{ мм}$ в масштабе 1:45), $Y = 0.0$, радиус $55\text{ мм}$ (диаметр $2.4\text{ мм}$ в 1:45).
- **Кормовое отверстие:** $X = 1500.0\text{ мм}$ ($X = 33.33\text{ мм}$ в масштабе 1:45), $Y = 0.0$, радиус $55\text{ мм}$ (диаметр $2.4\text{ мм}$ в 1:45).

**Любые доработки палубы ДОЛЖНЫ сохранять эти же ответные отверстия в `m_deck_split` при $Z=0$!** Иначе половинки не состыкуются штифтами.

### ⚠️ ПРАВИЛО 2: Прямые линии должны оставаться чистыми плоскостями
Требование пользователя: *"где должны быть прямые линии, обойтись без полигонов"*.
- Носовой наклонный скат рубки, крыша рубки, банки кокпита, пол кокпита, транец и плоскость КВЛ должны быть **строго плоскими** (линейная интерполяция, coplanar вершины).
- Не допускайте волнообразных сплайнов или ступенчатой триангуляции на плоских гранях.
- В рендерах (`render_v3_clean.py`) используйте `edgecolor='none'` и шейдинг по нормалям, чтобы не рисовать паутину триангуляции на плоских поверхностях.

### ⚠️ ПРАВИЛО 3: Только 100% Watertight Manifold
Любая сгенерированная модель должна выдавать:
```python
assert mesh.is_watertight == True
```
Слайсер FlashPrint выдаст ошибку или испортит слои, если в модели будут дыры или пересекающиеся внутренние грани.

### ⚠️ ПРАВИЛО 4: Проходы только на крыше
В Jouët Sheriff 600 **нет бортовых дорожек рядом с рубкой** (full-beam coachroof). Стенки рубки начинаются прямо от привального бруса. Ходят по крыше рубки.

## 5. Стандартный рабочий процесс доработки

Когда пользователь присылает фото и размеры:
1. Внимательно проанализируйте изменения (например, угол наклона переборки, положение люка, форма релингов или уток).
2. Отредактируйте логику палубы в функции `get_sheriff_ring()` в `generate_sheriff_models.py` (или добавьте накладные элементы через `manifold3d` булевы объединения).
3. Запустите генератор:
   ```bash
   python generate_sheriff_models.py
   ```
   Убедитесь, что все модели экспортировались со статусом `Watertight: True`.
4. Запустите чистый рендерер:
   ```bash
   python render_v3_clean.py
   ```
5. Проверьте полученную картинку `stl_output/Jouet_Sheriff_3D_Renders.png`.
6. Сделайте `git commit` и `git push`.
