# ⛵ Jouët Sheriff 600 — Высокоточная 3D модель для печати

Параметрическая 3D-модель классической французской парусной яхты **Jouët Sheriff 600** (конструктор — **Philippe Harlé**, верфь — **Yachting France**, 1969–1976 гг.), созданная по оригинальным чертежам теоретического чертежа (Lines Plan) из журнала *Bateaux* (октябрь 1969 и июль 1973), официальной документации верфи и архивным фотографиям.

Модель полностью твердотельная (100% Watertight 2-manifold) и оптимизирована для FDM 3D-принтера **Flashforge Adventurer 3** (область печати 150 × 150 × 150 мм) в масштабе **1:45**, а также экспортирована в масштабе **1:1**.

## 📐 Характеристики прототипа (Jouët Sheriff 600)

- **Длина наибольшая (LOA):** 6.00 м (6000 мм)
- **Длина по КВЛ (LWL):** 5.00 м (5000 мм)
- **Ширина наибольшая (Bmax):** 2.31 м (2310 мм)
- **Осадка (Draft):** 0.85 м (чугунный фальшкиль)
- **Высота надводного борта:** нос — 980 мм, мидель — 760 мм, транец — 650 мм
- **Водоизмещение:** ~850 кг (балласт 300 кг)
- **Материал оригинала:** Стеклопластик (GRP)

## 🧩 Особенности геометрии версии V3

1. **Рубка во всю ширину (Full-beam Coachroof):**
   - В соответствии с оригиналом на лодке отсутствуют утопленные бортовые проходы (walkways) вдоль рубки. Стенки рубки начинаются практически от привального бруса/фальшборта. Проход на нос осуществляется по плоской нескользящей крыше рубки.
2. **Световой люк / окно на переднем скате:**
   - Расположено на верхнем участке наклонного плоского носового ската рубки и **слегка заходит на крышу рубки**, а не лежит внизу на баке. Окно имеет рельефную рамку и плоское стекло.
3. **Рельефные контуры боковых иллюминаторов:**
   - На боковых наклонных стенках рубки сформированы характерные трапециевидные рамки иллюминаторов.
4. **Кокпит и закругления:**
   - Кормовые банки у транца заужены (280 мм в 1:1).
   - В средней части кокпита — широкие удобные банки (420 мм) и углубленный пол (слани / footwell).
   - У входа в рубку (сходного трапа) комингсы плавно **закругляются** внутрь к переборке.
5. **Транец, навесной руль и румпель:**
   - Транец абсолютно сплошной и монолитный (румпель не врезается в корпус).
   - Перо руля с щеками навешивается на транец снаружи.
   - Изогнутый румпель крепится к верхней головке баллера руля и проходит **над транцем**, нависая над кокпитом.
6. **Чистые прямые линии без полигональных волн:**
   - Все плоские участки (носовой скат, банки, пол, крыша, транец) являются математически точными плоскостями без волнообразных искажений сетки.

## 🖨️ Рекомендации по печати на Flashforge Adventurer 3

1. **Слайсер:** FlashPrint (или Cura / OrcaSlicer с профилем Adventurer 3).
2. **Материал:** PLA (белый для палубы/корпуса, коричневый/серый для руля и кильблока).
3. **Высота слоя:** `0.18 мм` (стандарт) или `0.12 мм` (высокая детализация).
4. **Стенки (Shells):** 2 периметра (0.8 мм).
5. **Заполнение (Infill):** 15% (Gyroid или Hexagon).
6. **Сборка разборной модели (`Split_Deck` + `Split_Keel`):**
   - Обе детали имеют ответные отверстия диаметром ~2.4 мм и глубиной 4 мм на плоскости ватерлинии.
   - Отрежьте два кусочка обычного прутка PLA 1.75 мм длиной по 7–8 мм.
   - Вставьте их в отверстия в качестве центровочных штифтов и соедините половинки на каплю цианакрилатного клея (суперклея).

## 🛠️ Структура скриптов и генерация

- **`generate_sheriff_models.py`** — Главный генератор всех STL и OBJ моделей.
  - Использует сплайны по 13 шпангоутам из официального теоретического чертежа.
  - Генерирует непрерывные замкнутые шпангоутные кольца (Ring Topology), гарантируя 100% топологическую замкнутость (2-manifold).
  - Выполняет булевы операции (CSG) через библиотеку `manifold3d`.
- **`render_v3_clean.py`** — Скрипт рендеринга предпросмотра с расчетом диффузного освещения без отображения триангуляционной сетки на плоскостях.
- **`chez_downloads/`** и **`extracted_pdf_assets/`** — Исходные материалы, PDF выпусков журнала *Bateaux* и извлеченные сканы чертежей.

### Запуск генератора:
```bash
python generate_sheriff_models.py
python render_v3_clean.py
```
